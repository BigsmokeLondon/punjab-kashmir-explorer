OPEN ON YOUR COMPUTER
1. On Windows with Python 3 installed, double-click Open_Website_Windows.cmd.
2. Your browser will open http://127.0.0.1:8000/.
3. Keep the server window open while browsing. Close it when you finish.

The local server binds only to your computer. It does not publish the website.
If you prefer a command, open a terminal in this folder and run:

Windows:
  py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist

macOS or Linux:
  python3 -m http.server 8000 --bind 127.0.0.1 --directory dist

If port 8000 is already in use, replace it with 8001 in the command and address.
Full-book search needs the local server because browsers restrict fetching
local files. Archival and other external source links need an internet connection.

UPDATE THE PRIVATE CLAUDE.AI COPY
After changing anything in dist/, run:
  python make_artifact.py <staging folder>
then republish the staged files to the same claude.ai page (Claude can do this;
give it the link above). files.json in the staging folder lists where each file goes.

YOUR REVIEW NOTES
Saved records, review marks and notes live in the browser you use, separately
for each copy (local, GitHub website, claude.ai). They are never uploaded.
Use "Copy saved" to copy your saved records, with their qualifications and
your notes, to the clipboard.

EDITABLE SOURCE
Edit prepare-data.py and book_research.py, then run python prepare-data.py
to regenerate the record and passage data, and node check.mjs to test it.
README.md explains the project. artwork-brief.md documents the images and prompts.
The design report (dist/assets/Punjab_Kashmir_Design_Report.docx) and the
original banner (dist/assets/history/heritage-panorama.png) are in the public
repository but are not part of the published website.

HISTORICAL CONTEXT
The book describes the 1881 census, first published in 1883 and reprinted in
1916. Keep origin claims attributed and historical localities dated. The
book's classifications do not establish current distribution or family ancestry.
